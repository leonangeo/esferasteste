# Simulador de Retrorreflexão em Microesferas Viárias

Este projeto open source simula computacionalmente como a luz dos faróis reflete nas microesferas de vidro da sinalização viária e retorna aos olhos do motorista. O modelo utiliza as Leis de Snell para traçar o caminho óptico e segue os padrões geométricos da norma DNIT 409/2017-PRO.

🌐 **[Acesse o simulador online](https://projetoesferas.streamlit.app/)**

**Tecnologias:** Python, Streamlit e Plotly.

### 🤝 Como contribuir
Este script é um material aberto à comunidade acadêmica e técnica. Sinta-se à vontade para ler o código, testar a lógica e colaborar 

* Tem alguma ideia para aprimorar a física do modelo (como incluir os efeitos de Fresnel ou feixes de luz) ou encontrou algum problema? **Abra uma Issue**.
* Quer implementar melhorias diretamente no código? **Faça um fork e envie um Pull Request (PR)**. Toda ajuda é muito bem-vinda!
